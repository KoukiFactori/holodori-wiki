## Le problème

Après avoir installé le jeu avec un compte Google créé via VPN (voir la page [Installation](./installation.md)), il arrive que le paiement échoue au moment d'effectuer un achat dans le jeu. C'est généralement dû au fait que le compte, ou son profil de paiement, n'est pas (ou plus) associé au bon pays.

Si vous êtes dans ce cas, la marche à suivre ci-dessous permet de vérifier et de corriger la situation. **Toutes les étapes sont à effectuer en étant connecté au VPN**, sur un serveur du pays dans lequel le compte a été créé.

## Vérifier la localisation du compte

1. Allez dans les paramètres du compte Google que vous avez créé.
2. Ouvrez l'onglet **Données et confidentialité**, puis descendez jusqu'à la section **Outils** et cliquez sur **Google Dashboard**.
3. Dans le Dashboard, vérifiez que vous êtes bien localisé dans le pays où vous avez créé le compte Gmail avec le VPN.
4. Si ce n'est pas le cas, regardez si Google vous propose de changer de pays en ajoutant une méthode de paiement.

## Corriger le profil de paiement

1. Toujours dans Google Dashboard, ouvrez la section **Paiements** (Google Pay).
2. Mettez le profil de paiement sur le pays qu'il faut, ou supprimez carrément le profil FR s'il en existe un.

## Moyen de paiement

Une fois le profil corrigé, retentez l'achat dans le jeu.
